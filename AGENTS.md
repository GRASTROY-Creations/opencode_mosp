# Agent instructions

Before any work, read and follow (priority order inside):

- `.docs/guide/agents.md` — agent rules incl. **git/svn read-only** (no commit, stage, checkout, pull, push, …) and the security guideline
- `.docs/guide/coding-standard.md` — coding standard and workflow (`bun run format`, `bun run check`)
- `.docs/guide/versioning.md` — set `package.json` version for the next commit

All documentation lives in `.docs/` (index: `.docs/README.md`); log every `.docs` change in `.docs/CHANGELOG.md` and never delete knowledge.
